# Photo credits

All location imagery is freely licensed from [Wikimedia Commons](https://commons.wikimedia.org/)
and served directly from `upload.wikimedia.org` (hotlinking permitted, CDN-backed).
Each URL was verified to return HTTP 200 with an image content-type before use.

Attribution follows each file's license. `CC BY` / `CC BY-SA` require crediting the
author; `CC0` is public-domain and needs no attribution (credited here anyway).
Locations without a reliably-verifiable Commons image keep the themed gradient
fallback (Balboa Park, Carmel-by-the-Sea).

Images are requested at a 1280px-wide thumbnail to keep payloads small.
